# Langkah terakhir menuju rilis AWAPART 66

Paket ini berisi proyek Android + starter backend. Ini belum server yang sudah online dan belum APK yang sudah dikompilasi/ditandatangani.

Yang diperlukan dari pemilik:
- VPS/hosting yang mendukung Docker + PostgreSQL, atau akun cloud database dan hosting API.
- Domain/subdomain API (contoh: api.domain-perusahaan.id) dan akses DNS.
- Konfirmasi Android application ID dan nama tampilan (saat ini id.co.awapart66.app / AWAPART 66).
- Persetujuan kebijakan privasi, syarat sewa, pembatalan/refund.
- Admin memeriksa mutasi rekening BCA secara manual sebelum verifikasi.

Jangan kirim password, OTP, private key, atau password keystore melalui chat.
Untuk APK rilis: build dengan Android SDK/Gradle, uji di perangkat fisik, lalu sign memakai keystore yang dibuat dan disimpan pemilik. File APK belum tersedia dalam paket ini.
